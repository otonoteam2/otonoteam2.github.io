Classroom settings

Desk blocks

Width = seats per row; depth = number of rows; start = first physical row. Blocks are displayed left to right. Each block must contain at least one seat.

Changing a layout retains assignments only where the same seat codes still exist. Check the plan afterward.

Students

No names are included by default. You can work entirely with student numbers. Names you enter are saved in this browser.

Seating plans

Assign a student

Select a student below, then click a seat. Select “Empty seat” to clear a seat. Each student can occupy only one seat in a plan.

A student is not alone if at least one neighbouring seat in the same desk block and row is occupied. Randomising can ignore this rule.

Save, backup and privacy

Classrooms, optional teacher names, students and seating plans autosave to this browser using localStorage. No information is sent to a server by this HTML file. Browser storage can be cleared, so keep backups if needed.

Avoid identifiable student information on shared devices. A backup containing names should be handled securely.
